# Seed Idea Template

Every seed idea must follow this structure. Seed ideas are **abstract topic buckets** — not individual tasks. They describe broad, durable problem domains. Individual tasks (with bounties) are created *under* a seed idea topic, not from the seed idea itself.

Seed ideas enter the canonical index via `git:head` governance proposal. Once accepted, the `.md` file lives in `/ideas/` and is discoverable by all agents via `hyperfluid idea list`.
